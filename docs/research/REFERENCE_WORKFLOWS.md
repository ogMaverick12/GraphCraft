## Black-box acceptance tests (behaviour, not copied code)
- GS-ERR-01: given rows `y=x^2` (valid) + `y=sin(` (incomplete), valid row renders, error row shows row-local message with position hint, no global crash. Alternatives: modal error (rejected: blocks valid work) vs row-local (chosen: preserves context).
- GS-VP-01: wheel-zoom anchors under cursor within 1px tolerance at 100%→200%; drag-pan translates centre exactly by cursor delta; `0` or reset button restores default viewport; keyboard `+`/`-`/arrows operable. Alternatives: button-only zoom (rejected: slow) vs gesture + keyboard (chosen).
- DATA-01: linear fit on 5-point dataset with σ yields slope/intercept within stated tolerance + residuals plot + export byte-identical on re-run given fixed metadata. Alternatives: silent fit (rejected) vs reported uncertainties (chosen: honest limitations).
- GS-MATH-01: `1/0`, `sqrt(-1)` (real mode), 10k-char input, and `while(true)`-style abuse each map to typed errors within deadline; UI never freezes (deferred/worker). Alternatives: raw `evaluate` (rejected) vs wrapped + capped (chosen).
- DATA-02: Plotly adoption requires written evaluation (fidelity, bundle size, licence, maintenance) or it stays out.
