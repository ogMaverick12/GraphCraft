## 3. Production bundle (task item 3)

Fresh build from the gate run above. Method (reproducible):

- raw = on-disk byte count; gzip = `node:zlib.gzipSync(fileBytes)` at
  default level, per file; unit = KiB (binary). Vite's own reporter
  prints decimal kB for the same bytes (index: ~811.31 kB decimal =
  792.3 KiB) — same file, different unit.
- Script (also archived at `%TEMP%\opencode\bundle-sizes.mjs`):

```js
// Usage: node bundle-sizes.mjs dist
import { readdirSync, readFileSync, statSync } from 'node:fs'
import { gzipSync } from 'node:zlib'
import { join, relative } from 'node:path'

const root = process.argv[2] ?? 'dist'
const files = []
const walk = (dir) => {
  for (const e of readdirSync(dir, { withFileTypes: true })) {
    const p = join(dir, e.name)
    if (e.isDirectory()) walk(p)
    else files.push(p)
  }
}
walk(root)
const rel = (p) => relative(root, p).split('\\').join('/')
const k = (n) => (n / 1024).toFixed(1)

let raw = 0
let gz = 0
for (const f of files.sort()) {
  const bytes = statSync(f).size
  const gzb = gzipSync(readFileSync(f)).length
  if (/\.(js|css)$/.test(f)) {
    raw += bytes
    gz += gzb
  }
  console.log(`${rel(f)}  raw ${bytes} B (${k(bytes)} KiB)  gzip ${gzb} B (${k(gzb)} KiB)`)
}
console.log(`TOTAL assets js+css: raw ${raw} B (${k(raw)} KiB)  gzip ${gz} B (${k(gz)} KiB)`)
```

## 4. Benchmark suite (task items 4 and 5)

Method:

- Command: `npx vitest bench src/perf` — tinybench through Vitest 4.1.11,
  default warmup/time, node environment (no jsdom), fixtures constructed
  once at module scope.
- Two independent full runs (A, B), minutes apart, same machine, same
  process settings; raw outputs archived at `%TEMP%\opencode\bench-run-A.txt`
  and `bench-run-B.txt`.
- tinybench reports mean / min / max / p75 / p99 / p995 / p999 and rme.

## 5. Provisional performance budgets (task item 6)

Derivation rule (deliberately simple and auditable):

- Batch/one-shot work → **mean budget** = worst observed mean across the
  comparable runs (A, B, plus the audit value where it is the worst) ×
  1.25, rounded up.
- Frame-sensitive work → **p99 budget** = worst observed p99 × 1.25.
- These are provisional regression tripwires on this machine, not
  universal targets; re-derive at S7.5 close from fresh runs run with
  this same method.
