# Code of Conduct

GraphCraft is a learning tool built by and for students, teachers, and
researchers. Everyone is welcome.

## Expectations

- Be kind and patient, especially with beginners and non-native
  English speakers. Assume good faith.
- Critique code and ideas, never people. No harassment, insults,
  slurs, or unwelcome advances, in any venue.
- Respect scope: keep threads on the issue at hand; open a new issue
  for a new problem.
- Respect licences and trademarks: contribute only original work or
  content you have the right to share.

## Enforcement

Maintainers may warn, hide, or remove content and, for repeated or
serious violations, temporarily or permanently ban contributors. Report
concerns privately to the maintainers via a GitHub private report or
the contact in `SECURITY.md`. Reports are handled confidentially; no
retaliation is tolerated.
